# Barqode Brand

This repository is the single source of truth for the Barqode brand.

It defines how Barqode looks, speaks and behaves across:

* Product interfaces
* Landing pages and websites
* Presentations and pitch decks
* Documentation
* Sales and marketing collateral
* Social media
* Internal and external communications

Every designer, developer, agency, contractor and AI tool working on Barqode should review this repository before creating or changing any branded material.

If an output conflicts with the guidelines in this repository, the guidelines in this repository take priority.

## Brand documents

* `01-brand.md` — Brand foundation, positioning, audience and personality
* `02-visual-language.md` — Creative direction and visual identity
* `03-design-system.md` — Colours, typography, layout and interface rules
* `04-logo.md` — Logo concept, construction and usage
* `05-voice.md` — Language, tone and writing principles

## Current status

This brand system is being developed from the ground up.

The documents will evolve as the identity is tested across the Barqode website, product and marketing materials.
