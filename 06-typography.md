# 06 — Typography

> This document defines the principles that govern typography throughout the Barqode ecosystem.
>
> Typography is the primary interface between the operator and information.
>
> Every typographic decision should improve clarity, recognition and operational speed.

---

# Typography Philosophy

Typography exists to make information accessible, readable and understandable in every environment.

It should communicate importance before the operator consciously begins reading.

Typography is not used to impress.

It is used to remove friction.

Every letter, number, label and heading should help an operator complete their work with greater confidence and less effort.

The objective is not beautiful typography.

The objective is effortless reading.

---

# Information Before Expression

Typography should communicate information before personality.

Visual expression should never reduce clarity.

The operator should not notice the typography.

They should notice the information.

A successful typographic system disappears behind the work being performed.

When typography becomes the focus, it has failed.

---

# Reading Under Pressure

Barqode is designed for environments where decisions are made quickly.

Typography should remain readable:

- Under time pressure.
- On older hardware.
- On low-resolution displays.
- In poor lighting.
- At different viewing distances.
- During long operational shifts.

Typography should reduce fatigue rather than contribute to it.

Information should remain clear regardless of the environment in which it is viewed.

---

# Information Hierarchy

Typography communicates priority before content.

The operator should immediately understand:

- What requires attention.
- What requires action.
- What is informational.
- What is secondary.
- What can be ignored for now.

Hierarchy should primarily be created through:

- Weight.
- Size.
- Spacing.
- Position.

Colour should reinforce hierarchy rather than create it.

If every piece of text appears equally important, then none of it is.

---

# Operational State

Operational software is driven by status rather than identity.

The most important question is rarely:

> "What is this?"

It is:

> "What state is it in?"

Typography should therefore communicate operational state before identifiers, descriptions or metadata.

Status should be immediately visible and easy to scan.

Operators should be able to identify blocked work, warnings, pending actions and completed tasks before reading the rest of the record.

The state determines the action.

The identifier simply tells the operator which item is in that state.

---

# Data and Numbers

Operational systems are dominated by structured data.

Typography should present numbers with consistency and precision.

This includes:

- Order numbers.
- Tracking numbers.
- SKUs.
- Quantities.
- Dimensions.
- Dates.
- Times.
- Prices.
- Weights.
- Percentages.

Where practical, numerical data should use tabular figures so values align vertically.

Numerical columns should align consistently.

Decimal places should align.

Currency values should align.

Units should remain consistent within a column.

The operator should be able to compare values without visual effort.

Numbers should feel engineered.

Never decorative.

---

# Tables

Tables are the primary interface of Barqode.

Typography inside tables should optimise scanning before aesthetics.

Every row should be understandable at a glance.

Column headings should clearly communicate the information beneath them.

Important operational values should stand out through hierarchy rather than excessive styling.

Typography should allow operators to scan thousands of rows without losing orientation.

Compact typography should improve efficiency without sacrificing readability.

---

# Labels and Identifiers

Operational identifiers should remain immediately recognisable.

Examples include:

- Order IDs.
- Tracking numbers.
- SKUs.
- Shipment references.
- Carrier references.
- Warehouse locations.

Typography should clearly distinguish:

- Labels.
- Values.
- Statuses.
- Actions.
- Supporting information.

Operators should never wonder whether they are reading an identifier, a heading or descriptive text.

---

# Density

Typography should support high-density interfaces.

Warehouse operators often prefer seeing more information within a single view provided that information remains organised.

Whitespace separates ideas.

Typography separates information.

Large empty spaces should never replace good hierarchy.

Dense does not mean crowded.

Compact does not mean difficult to read.

The objective is maximum useful information with minimum cognitive effort.

---

# Website and Product

Typography should adapt to its environment.

The Barqode product exists to help operators complete work.

The Barqode website exists to communicate the company.

Both should share the same underlying principles while serving different objectives.

The product should prioritise operational clarity.

The website may communicate more personality, storytelling and brand expression.

The product should disappear behind the work.

The website should introduce the people, thinking and philosophy behind Barqode.

Consistency should come from shared principles rather than identical presentation.

---

# Choosing a Typeface

Barqode does not choose a typeface because it is fashionable.

A typeface must satisfy operational requirements.

The primary typeface should be:

- Highly readable.
- Neutral.
- Dependable.
- Clear at small sizes.
- Clear on older displays.
- Easy to distinguish similar characters such as:
  - I
  - l
  - 1
  - O
  - 0
- Suitable for dense interfaces.
- Suitable for documentation.
- Suitable for marketing.
- Available across modern and older operating systems.
- Supported by multiple weights.
- Suitable for international languages.

A single primary typeface is preferred unless there is a compelling operational reason to introduce another.

Additional typefaces should solve a genuine communication problem rather than introduce visual variety.

Consistency should always outweigh novelty.

---

# Accessibility

Typography must remain readable for every operator.

It should support users of different ages, abilities and working environments.

Typography should maintain:

- Clear letterforms.
- Strong contrast.
- Comfortable spacing.
- Predictable hierarchy.
- Practical reading sizes.

Information must never rely solely on colour.

Accessibility is fundamental to operational reliability.

---

# Consistency

Typography should behave consistently throughout the Barqode ecosystem.

An order number should always look like an order number.

A warning should always look like a warning.

A heading should always feel like a heading.

Consistency reduces learning.

Consistency increases confidence.

Consistency improves speed.

---

# Final Principle

Typography is the primary interface between the operator and information.

Its purpose is not to decorate the interface.

Its purpose is to make information immediately understandable.

Every typographic decision should reduce thinking, improve recognition and help the operator complete their work with confidence.

When typography disappears and the information becomes effortless to read, it has succeeded.
